# 0011. Мир «Журнал обходчика» вместо тёмного HUD

## Контекст

2026-11-22 пользователь попросил редизайн уровня студийной работы для дизайн-конкурсов: смелая система
без клише генераторов, асимметричная сетка 8 px, акцидентная типографика, своя векторная и интерактивная
графика, генерация изображений и видео в Gemini. Прошлый вид (почти чёрный фон, оранжевый акцент,
моно-метки, ADR 0006–0010) попадал в самый частый кластер сгенерированных лендингов, а голубой «луч
сканирования» в ролике hero изображал то, чего в продукте нет. Разбор — `docs/design/references.md`.

## Решение

Страница — сменный журнал обхода котельного цеха, который пишет сам. Серо-зелёная бумага с линовкой 2rem,
двойное красное поле слева, ярлыки листов у правого края. Три голоса шрифта: Sofia Sans Extra Condensed —
печать бланка в кегле плаката, Martian Mono — машинные строки и цифры, Bad Script фиолетовыми чернилами —
рука обходчика. Тёмные поверхности — только вклеенные кадры камеры.

Порядок листов: журнал (hero) → смена (было и стало) → показание → конвейер → протокол → схема →
замечания → сдача смены. Было и стало поднято на второй лист: проблему показываем до механизма.
Новый ролик Gemini сделан по двум ключевым кадрам: обходчик пишет в журнал → на том же месте камера.

## Почему

- Полировать тёмный HUD отвергнуто: пользователь прямо попросил отказаться от клише, а этот вид
  угадывается по категории продукта.
- Направление выбрано броском `impeccable concept-seed` (кандидат 4 из 7 собственного списка);
  пользователь ответил «продолжай» вместо выбора карточки. Сид и подъёмы записаны в surface brief.
- Журнал — та самая вещь, которую продукт заменяет, поэтому метафора работает как аргумент, а не декор.

## Последствия

- Договорённости прошлых сборок «светлого фона нет», «шрифт Onest / Manrope», «фон в Tweaks» сняты этим
  редизайном по новому запросу пользователя; Tweaks теперь меняет масштаб и сорт бумаги.
- Модули переименованы: `journal`, `shift`, `operations`, `contact`; `scroll-video`, `pipeline-track`,
  `compare` удалены. `check.js` сверяет новый порядок листов и медиа ролика, правила о фактах прежние.
- В `main` новая версия попадает только после подтверждения пользователя (публикация через Pages).
