# 0008. Видео hero привязано к прокрутке и идёт из перекодированных копий

## Контекст

Бриф просит, чтобы видео котельной отъезжало от манометра кадр за кадром при прокрутке, с инерцией, а оригинал сохранить. Исходник — Gemini-ролик с редкими ключевыми кадрами. Сайт открывается по file://, где `fetch` локальных файлов не работает. ffmpeg доступен через `imageio_ffmpeg`.

## Решение

`currentTime` обычного `<video muted playsinline preload="auto">` тянется к цели «прогресс × длительность» с инерцией в rAF; `play()` не вызывается. Для перемотки сделаны две копии без звука, где каждый кадр ключевой: 1280×720 и 854×480 для узких экранов. Оригинал лежит в `site/assets/video/` без изменений и побайтно равен исходнику в `references/`. Команды ffmpeg записаны рядом. При ошибке видео и при «уменьшить движение» показывается постер — первый кадр ролика.

## Почему

- Перемотка оригинала отвергнута: при редких ключевых кадрах каждый скачок `currentTime` заставляет декодер собирать кадр от дальнего ключевого, и видео рвётся. Копия с ключевым кадром на каждом кадре платит размером файла, но даёт плавность.
- Покадровая последовательность картинок отвергнута: сотни JPEG тяжелее одного видео при том же качестве, нужен canvas, а загрузка из file:// осложняется.
- Воспроизведение через `play()` с подбором скорости отвергнуто: бриф требует кадр за кадром в обе стороны, а обратное воспроизведение браузеры не дают.
- Загрузка через `fetch`/blob отвергнута: по file:// не работает.
- Хранить только копии отвергнуто: бриф требует сохранить оригинал, а копии пересоздаются только из него.

## Последствия

- Репозиторий растёт на три видеофайла, и каждая смена ролика требует перекодирования по записанным командам.
- Перемотка надёжна только по file:// или на сервере с Range-запросами; `python -m http.server` Range не поддерживает, и там видео стоит на кадре 0. Проверять нужно двойным кликом.
- Мобильная копия выбирается один раз при загрузке по ширине экрана; поворот телефона её не меняет.
- Копия выглядит чуть хуже оригинала: качество отдано ради ключевых кадров.
