Смартфон как Wi-Fi камера

Установка приложений не требуется — используется браузер смартфона (Safari / Chrome).
  1. Смартфон и сервер должны быть в одной сети Wi-Fi / LAN.
  2. Отсканируйте QR-код штатной камерой телефона и откройте ссылку.
  3. При первом входе примите самоподписный сертификат («Дополнительно» → «Перейти на сайт» / «Подробнее» → «посетить веб-сайт»).
  4. Разрешите доступ к камере, выберите объектив и нажмите «Начать трансляцию».
