## Что должно заработать

`site/index.html` открывается с диска. Сверху тонкая студийная панель с кнопками вариантов: пока ни один вариант не зарегистрирован, она честно показывает, что вариантов нет, и не выводит мёртвых кнопок. В правом нижнем углу плавающая кнопка Tweaks открывает панель: шрифты, четыре фона (включая «Бумагу»), масштаб и режим изображений. Изменения сразу видны на странице — фон, шрифт и масштаб тестового текста в `#gv-root`, — сохраняются после перезагрузки и сбрасываются кнопкой. В `js/content.js` лежат все факты для семи экранов, вычитанные из README, PRODUCT.md и `notes.md`, а `node site/tests/check.js` подтверждает, что ни одно число не выдумано. В `site/design-system.md` записаны правила дизайна, выведенные из шести референсов, и описаны три варианта.

## Критерии приёмки

- [ ] `site/index.html`: `lang="ru"`, мета viewport/description/theme-color, студийная панель `#gv-studio`, `<main id="gv-root">`, `<noscript>` (название, фраза, ссылка на GitHub), скрипты в порядке из `interfaces.md`, классические, без `type="module"`; по `file://` консоль без ошибок
- [ ] `js/content.js` содержит все поля формы `GV.content` из `interfaces.md` (включая `tradeoffs`, `screenshotFacts`), заполненные реальными русскими текстами для всех семи экранов и всех историй спецификации; ни одного «lorem», «TODO» или пустой строки там, где вариант будет её показывать
- [ ] Этапы `pipeline` 00–08 описаны по коду (`notes.md` §1), а не по README, там, где они расходятся; запрещённое правилом 1a отсутствует
- [ ] `css/tokens.css`: все обязательные токены; четыре `[data-bg]`, причём на «Бумаге» контраст основного и приглушённого текста ≥ 4,5:1; три `[data-font]`; `--ui-scale`; токены вариантов-заглушек `[data-variant="a|b|c"]` (акцент и шрифты по умолчанию из спецификации)
- [ ] Шрифты Manrope, JetBrains Mono, Onest, IBM Plex Sans, IBM Plex Mono лежат локально в `assets/fonts/` (кириллица + латиница, нужные начертания) и подключены в `css/fonts.css` с `font-display: swap`
- [ ] `GV.app`: читает `?v=` → localStorage → `a`; показывает в панели только варианты, которые есть в `GV.variants`; переключение вызывает cleanup, затем render, `replaceState` и восстановление позиции по секции. Временный вариант для проверки работает и удаляется перед коммитом
- [ ] `GV.tweaks`: плавающая кнопка «Tweaks», панель с 4 группами (шрифт: по варианту / Manrope / Onest / Plex; фон: Графит / Антрацит / Сине-графитовый / Бумага; масштаб: 90 / 100 / 110 / 125 %; изображения: Скриншоты / Схема) на нативных radio или кнопках с `aria-pressed`; «Сбросить»; Esc закрывает и возвращает фокус; localStorage `gv.tweaks`; событие `gv:tweaks`; атрибуты применяются до первого рендера (нет вспышки графита при сохранённой «Бумаге»)
- [ ] На 390 px студийная панель и кнопка Tweaks не дают горизонтальной прокрутки, а цели касания ≥ 44 px
- [ ] `node site/tests/check.js` проверяет все 5 пунктов шва из `interfaces.md`, выходит с кодом 0 на текущем `site/` и с ненулевым кодом, если в `content.js` подставить выдуманное число (проверь и откати)
- [ ] `site/design-system.md`: по каждому из 6 референсов «берём / не берём и почему», таблица токенов (совпадает с `tokens.css`), типографическая шкала, сетка и отступы, линии, движение (easing, длительности, reduced motion), правила статусных цветов, описание трёх вариантов (композиция hero, подача метрик, форма конвейера, акцент, шрифты), правила Tweaks, чек-лист доступности
