# Усовершенствование и независимая валидация прогнозной аналитики (`PREDICTIVE_ANALYTICS_REVIEW.md`)

Дата: 2026-11-28. Контрольный коммит: `1de2067`.
Модуль: `app/predictive_analytics.py` (`PredictiveAnalyzer` v3.2).
Сырые доказательства: `evidence/predictive/predictive_v3_dev.json`, `predictive_v31_dev.json`, `predictive_v32_dev.json`, `predictive_v32_locked_test.json`.

## 1. Исходная проблема и гипотеза

По итогам независимой валидации версии 3.0 (`reports/next_generation/PREDICTIVE_REAL_DATA_VALIDATION.md`) на 4 реальных промышленных датасетах (SKAB, UCI 447 Hydraulic, UCI 791 MetroPT-3, UCI 551 Gas Turbine) были зафиксированы ограничения:
- низкая полнота прогнозирования пробоя уставки на горизонте `H = 30` (**4,65 %** на LOCKED TEST; `4,47 %` на DEV), уступавшая затухающему Хольту (`6,28 %` / `11,71 %`);
- высокая доля ложных срабатываний детектора аномалий (`FAR = 36,11 %` на LOCKED TEST; `39,88 %` на DEV).

**Первопричина:** в нелинейных/инерционных режимах глобальный WLS-наклон по 60-минутному окну сильно сжимался байесовским фактором и не успевал реагировать на локальный разгон параметра к уставке, а критерий Манна-Кендалла (`slope >= 0,03 %/мин`) и `mad_outliers` (по всему окну) срабатывали на штатных технологических переходах.

**Реализованное изменение (v3.2, без утечки будущего и без внешних зависимостей):**
1. Добавлен робастный локальный затухающий Хольт (`_robust_damped_holt` с Huber-клиппингом выбросов `> 3,5 MAD`) для привязки уровня и локального тренда в нелинейных режимах.
2. Разделены траектории: сглаженная траектория (`alpha=0,28, beta=0,08, phi=0,85`) для точного многошагового прогноза (без перелёта на `H=60`) и быстрый локальный Хольт (`alpha=0,30, beta=0,12, phi=0,88`) для ранней оценки ETA до уставки.
3. Ужесточены пороги ложноположительных правил (`mann_kendall_drift`: `|Z| >= 2,80` и `slope >= 0,14 %/мин`; `mad_outliers`: учёт свежести выбросов в последней трети окна и `count >= 3`).

## 2. Результаты на DEV (74 ряда, 3 330 origins) и LOCKED TEST (82 ряда, 3 690 origins)

Настройка выполнялась **строго на DEV**; выборка **LOCKED TEST** разблокирована однократно для финальной проверки.

### 2.3. Детектор аномальных трендов (`SKAB + MetroPT-3`, `LOCKED TEST`)

- **FAR (ложные тревоги):** снижен с `36,11 %` до **`33,75 %`** (−2,36 п.п.; на DEV с `39,88 %` до **`35,23 %`**).
- **Recall / Precision / F1:** `54,44 % / 50,19 % / 52,23 %` (против `58,96 % / 50,50 % / 54,40 %` в v3.0 — небольшой компромисс −2,17 п.п. F1 ради снижения ложных тревог).
- Все 5 математических и интеграционных тестов `tests/test_predictive_analytics.py` (линейный ETA, Монте-Карло покрытие PI95 = `92,67 %`, робастность Theil-Sen, честный STALE, Multi-Gauge + Modbus) — **5 / 5 PASS**.

## 3. Честные ограничения

Внезапные ступенчатые аварии без предшествующего плавного дрейфа (закрытие клапана SKAB, мгновенный разрыв магистрали) принципиально непредсказуемы одномерной экстраполяцией до момента срабатывания (отсюда остаточный `FNR = 92,0 %` на `H = 30`). Прогнозная подсистема остаётся статистическим советчиком и не заменяет ПАЗ/SIS.
