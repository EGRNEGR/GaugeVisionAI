## 1. Приоритизация улучшений (P0–P3)

| Приоритет | Направление | Исходная проблема | Принятое решение | Статус |
|---|---|---|---|---|
| **P0** | ML Security (`DEF-SEC-02`, `DEF-SEC-03`) | `gauge_yolov8.pt` загружался без SHA-256; пустой `sha256` пропускал проверку | Обязательный 64-симв. SHA-256 в `ModelRegistry` для всех моделей, включая YOLO | **DONE** (`1de2067`) |
| **P0** | CV Fuzzing Crash (`DEF-SEC-01`) | `assess_dial_suitability()` падал с `IndexError` на кадрах != `640×640` | Проверка минимального размера + ресайз к `640×640` | **DONE** (`1de2067`) |
| **P1** | API/LLM Security (`DEF-SEC-04..07`) | Нет `audit_log` для `/api/vision/profile`, нет лимита тела 10 МБ, нет CSRF Origin-check, нет `<FACTS>`-изоляции LLM | Реализовано и проверено негативными тестами `test_security_hardening_v31.py` | **DONE** (`1de2067`) |
| **P1** | CV Локализация `MeasureBench misc` | Базовый детектор давал `55,74 %` локализации на разнородных приборах | Каскадный `detect_dial_v31` (padded + lowconf + `NeedleSegUNet` dialness): `55,74 % → 63,93 %` без переобучения GPU | **DONE** (`1de2067`); цель ≥95 % ждёт RTX 3090 |
| **P1** | Прогнозная аналитика (`H=30` Recall) | Полнота прогноза пробоя уставки `4,65 %` (LOCKED TEST), FAR аномалий `36,11 %` | Predictive v3.2 (робастный локальный затухающий Хольт): Recall **`4,65 → 7,98 %` (×1,72)**, Precision **`66,4 → 77,2 %`**, Med AE **`−43 %`**, Anomaly FAR **`36,1 → 33,8 %`** | **DONE** (`1de2067`) |
| **P2** | База данных SQLite (`DEF-SEC-08`) | Нет `busy_timeout`, нет ротации `predictive_snapshots` | `PRAGMA busy_timeout=5000`, `cache_size=-16000`, очистка `predictive_snapshots` в `prune_history()` | **DONE** (`1de2067`) |
| **P2** | Пакет RTX 3090 | Необходима проверка воспроизводимости экспорта перед переносом | Dry-run `--stage export` выполнен успешно (`train=439, val=271`) | **DONE** (обучение заблокировано аппаратно) |
