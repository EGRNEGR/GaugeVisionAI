## Главные измеримые результаты

1. **Компьютерное зрение (`CV_IMPROVEMENT_REPORT.md`):**
   - Сохранены и усилены результаты `NeedleSegUNet` (320 КБ, MIT/BSD-3, `6,6 мс` CPU/кроп) и `OpenCVNeedleV2` (снижение грубых ошибок на проблемном приборе `M1` с **77 до 6** — в **12,8×**).
   - Каскадный локализатор `detect_dial_v31` поднял локализацию на разнородных приборах **`MeasureBench misc`** с `55,74 %` до **`63,93 %` (+8,2 п.п.)** без переобучения на GPU (ноутбук оснащён RTX 5060 с запретом нагрузки из-за WHEA/PCIe; локализация на `VAL M5` выросла до **`95,8 %`**, корректный отказ на `UNUSABLE` `n=300` — до **`99,33 %`**).
   - Подтверждён dry-run экспорта автономного пакета обучения `training_package_3090/` для Linux RTX 3090 24 ГБ (`train=439, val=271`).
   - Проверена масштабируемость Multi-Gauge при **1, 2, 4, 8 и 16 приборах** во всех 4 профилях (`16/16`, `MAE 0,17–0,36 %`).
2. **Прогнозная аналитика v3.2 (`PREDICTIVE_ANALYTICS_REVIEW.md`):**
   - На независимой закрытой выборке **`LOCKED TEST`** (82 реальных промышленных ряда SKAB / Hydraulic / MetroPT-3 / Gas Turbine, 3 690 origins): полнота прогноза пробоя уставки на `H = 30` выросла в **1,72×** (`4,65 % → 7,98 %`, обогнал `Holt Damped` `6,28 %`), точность — на **+10,9 п.п.** (`66,36 % → 77,22 %`), медианная ошибка ETA снижена на **43 %** (`11,33 → 6,41` шага), опережение выросло на **+25 %** (`5,89 → 7,34` шага), FAR детектора аномалий снижен (`36,11 % → 33,75 %`), NMAE на `H = 60` улучшена (`11,16 % → 10,95 %`).
3. **Информационная безопасность, ML Security и БД (`SECURITY_AUDIT_REPORT.md`, `ML_SECURITY_REPORT.md`, `SBOM.json`):**
   - Выявлены и закрыты **8 дефектов безопасности и надёжности (`DEF-SEC-01..08`)**: краш `IndexError` при fuzzing `assess_dial_suitability`, проверка SHA-256 для `gauge_yolov8.pt`, запрет пустого SHA-256 в `ModelRegistry`, `audit_log` для `/api/vision/profile`, лимит тела HTTP 10 МБ (`413`), проверка CSRF `Origin`, защита LLM от prompt injection (`<FACTS>`) и HTML, `PRAGMA busy_timeout=5000` и ротация `predictive_snapshots`.
