# Протокол строгого разделения данных (`DATASET_SPLIT_PROTOCOL.md`)

Дата: 2026-11-28. Ветка: `research/cv-next-gen`.
Скрипт формирования: `cv_next_gen/build_dataset_manifest.py`.
Зафиксированный манифест: `reports/cv_next_gen/evidence/dataset_manifest.json`.

## 1. Принципы предотвращения утечек

1. **Разделение по физическим моделям приборов и источникам**, а не случайное разбиение отдельных кадров.
2. **Дедупликация** по `SHA-256` и 64-битному `dHash` (расстояние Хэмминга ≤ 6): отброшено **104** дубликата между MeasureBench и MeterFL.
3. **Изоляция шаблонов синтетики**: `template_id` 0–699 используются только в `TRAIN`, 700–799 — только в `VALIDATION`, 800–999 — только в тестовых/стресс-проверках.
4. **Замораживание до финальных испытаний**: пороги согласования (`Intelligent Fusion`), архитектура и веса выбираются исключительно на `TRAIN` / `VALIDATION` и замораживаются до запуска на `LEGACY_BENCHMARK` и `LOCKED_FINAL_TEST`.

## 2. Состав выборок

| Выборка | Назначение | Источники и модели | Объём |
|---|---|---|---:|
| **TRAIN** | Обучение весов нейросетей | MeterFL `M2` (202) + `M3` (233) + синтетика `tid 0..699` (1200) | 435 реал. + 1200 синт. |
| **VALIDATION** | Ранняя остановка, выбор гиперпараметров, калибровка порогов Fusion и Risk-Coverage | MeterFL `M5` (71, невидимый при обучении физический прибор) + синтетика `tid 700..799` (160) | 71 реал. + 160 синт. |
| **DEVELOPMENT_BENCHMARK** | Инженерный анализ ошибок и сравнение с dev v7/v8 | MeterFL `dev` (`M2, M3, M5`) | 506 реал. |
| **LEGACY_BENCHMARK** | Совместимость и прямое сравнение с GaugeVision AI 3.0 (при обучении не используется) | MeterFL `M1` (664), `M4` (105), `M6` (53), `misc` + MeasureBench (114); `primary` = 315, `final` = 985, `unusable` = 300 | 985 реал. (+300 непригод.) |
| **LOCKED_FINAL_TEST** | Новая независимая оценка на ранее неиспользованных данных | IGVD (`1.- Analog Dial Gauge`, 18 видео, 2362 метки) + MeasureBench unused `dial` (509) + MeasureBench unused `digital/linear` (444) | 953 фото + 18 видео |
