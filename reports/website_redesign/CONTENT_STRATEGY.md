## Правила текста

1. **Каждая цифра — с источником.** Числа хранятся в `site/v4/js/content.js` рядом с ключом источника; ключ ведёт
   на документ неизменяемого тега `v3.0.0`. Полный реестр — `PRODUCT_CLAIMS_REGISTER.md`.
2. **Условие рядом с цифрой.** «8 приборов в Tag Historian Ignition 8.3.10, лабораторный стенд», «Прогноз
   13,18 мин при фактических 12,7 мин, синтетический дрейф».
3. **Ни одной выдуманной статистики.** Оценки команды v3 («до 60 % приборов», «−58 % затрат») убраны. Единственная
   оценка команды, которая осталась, — стоимость камеры 33 000 ₽ в калькуляторе; она подписана «оценка
   команды, v2», а поле можно изменить.
4. **Не путать понятия.** Локализация — не точность. Регистрация прибора на кадре — не точность показания.
   96,95 / 100 — оценка по матрице требований, а не точность нейросети. Две матрицы требований (исходная из 75
   требований и Next Generation из 6) показаны раздельно.
5. **Ограничение там же, где утверждение.** Предупреждение о 16 приборах выводится в самой секции «Щит», когда
   выбрано 16. Ограничения SCADA — под блоком SCADA. Полнота прогноза 4,65 % — в блоке прогноза и в ограничениях.
6. **Тип материала подписан на материале.** «Снимок реального приложения», «Интерактивная симуляция»,
   «Иллюстрация», «Синтетический стенд».
7. **Типографика.** Длинное тире с пробелами по правилам пунктуации, короткое тире в диапазонах, неразрывные
   пробелы перед единицами, без средней точки «·».

## Чего на сайте нет и почему

| Чего нет | Почему |
|---|---|
| «Надёжная работа с 16 приборами» | на реальных фото при 16 приборах годных показаний 47,9 % |
| «OPC UA», «прогнозные регистры проверены в Ignition» | не проверялось (`KNOWN_LIMITATIONS`) |
| «Средство измерений», «ПАЗ», «предотвращает аварии» | продукт — информационная система; полнота прогноза пересечений 4,65 %, ложные срабатывания детектора 36,1 % |
| Автокалибровка | не прошла предустановленные критерии (1 из 5), модуль выключен |
| «Окупаемость 5 мес.» со снимка пульта | демонстрационные данные пульта, не результат испытаний |
| Контакты, телефоны, имена заказчиков | их нет в источниках; связь — через issue на GitHub |
| «Готов к промышленной эксплуатации» | уровень готовности NOT READY; прототип подготовлен к ограниченному пилоту при условиях |

## Призывы к действию

«Смотреть в действии» (к истории), «Возможности 3.0», «Доказательства», «Посмотреть демонстрацию» (режим
демонстрации), «Документация» (README тега), «Результаты испытаний» (FINAL_ACCEPTANCE_REPORT), «Обсудить пилот
на GitHub» (новый issue с шаблоном: объект, число точек, цель). Других каналов связи в источниках нет, поэтому
на сайте их нет.
