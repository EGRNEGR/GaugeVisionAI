## 2. Правила работы с цифрами и фактами

1. **Единый источник истины.** Все тексты, числа и ссылки хранятся в `site/v5/js/content.js`. Каждый показатель снабжён ключом из карты `src`, ведущим на документ неизменяемого тега `v3.0.0` (коммит `0273436`). Полная сверка 50 заявлений приведена в [`PRODUCT_CLAIMS_REGISTER.md`](PRODUCT_CLAIMS_REGISTER.md).
2. **Условие рядом с цифрой.** Ни один результат синтетического или лабораторного прогона не подаётся без контекста: для Ignition указано «лабораторный стенд, один узел, пробная лицензия», для прогноза — «контролируемый синтетический дрейф», для щита — раздельно синтетика и мозаики реальных фото MeterFL.
3. **Разделение понятий.** Локализация (`79,0 %`) и регистрация прибора на кадре (`≥ 97,5 %`) явно отделены от точности показания. Оценка `96,95 / 100` подписана как методика аудита исходных 75 требований, а не точность нейросети; матрица Next Generation (`2 PASS / 3 PARTIAL / 1 FAILED`) показана отдельной строкой.
4. **Ограничение в месте утверждения.** При выборе `N = 16` на листе `03` открывается красная рамка про `47,9 %` годных показаний на реальных фото. На листе `05` сразу под перечнем протоколов стоит рамка про непроверенные OPC UA и прогнозные регистры в Ignition. На листе `06` рядом с прогнозом E2E раскрыт блок реальной валидации (`4,65 %` полноты, `36,1 %` ложных срабатываний).
5. **Отказ от неподтверждённых цифр v3.** Оценки команды из старой версии («до 60 % приборов ТЭЦ», «−58 % затрат») удалены. Единственная оставшаяся оценка команды — стоимость камеры `33 000 ₽` в редактируемом калькуляторе экономики, явно подписанная как «оценка команды, v2».
6. **Типографика.** Длинное тире с пробелами по правилам пунктуации, короткое тире в числовых диапазонах, десятичная запятая, неразрывные пробелы перед единицами, ноль средних точек `·` (U+00B7).

## 3. Запрещённые формулировки

| Формулировка, исключённая с сайта | Фактическое основание по `v3.0.0` |
|---|---|
| «Надёжная работа с 16 реальными приборами» | На мозаиках реальных фото MeterFL при `N = 16` годных показаний `47,9 %`; основной режим — `4–8` приборов |
| «OPC UA» или «прогнозные регистры проверены в Ignition» | Не проверялись (`KNOWN_LIMITATIONS.md`, `SCADA_REVALIDATION_REPORT.md`) |
| «Средство измерений», «ПАЗ», «предотвращает аварии» | Информационный прототип; полнота прогноза пересечений `4,65 %`, ложные срабатывания `36,1 %` |
| «Автоматическая калибровка шкалы» | Не прошла предустановленные критерии (`1 из 5`) и выключена; калибровка ручная по кадру |
| «Окупаемость 5 мес.» со снимка `hmi-dispatch.jpg` | Условные демонстрационные данные пульта на 36 позициях; в тексте сайта не утверждается |
| «Готов к промышленной эксплуатации» | По `FINAL_ACCEPTANCE_REPORT.md` статус промышленной эксплуатации — `NOT READY` |
| Телефоны, адреса почты, выдуманные заказчики | В источниках релиза отсутствуют; единственный канал связи — GitHub Issues |
