## 5. Ключевые продуктовые метрики (источник — тег `v3.0.0`)

Полный перечень из 50 заявлений и ссылок приведён в [`PRODUCT_CLAIMS_REGISTER.md`](PRODUCT_CLAIMS_REGISTER.md):
- **SCADA:** `19 / 19` этапов E2E с Ignition 8.3.10 (лабораторный стенд, один узел, пробная лицензия; OPC UA и прогнозные регистры в Ignition не проверялись).
- **Отказоустойчивость:** `10 309 / 10 309` MQTT-сообщений без разрывов за `61,9 мин` soak (`12` приборов, CPU, `6` отключений брокера, `4 / 4` восстановления RTSP, `0` ошибок сервера и Modbus).
- **Щит приборов:** на синтетике `100 %` годных, MAE `0,23–0,56 %`, `0` перепутанных ID; на реальных мозаиках MeterFL при `N ≤ 8` регистрация (не точность) `≥ 97,5 %`, годных `82,5–90,0 %`, медианная ошибка `1,08–1,53 %`; при `N = 16` годных только `47,9 %` (рекомендуется `4–8`).
- **Валидация CV:** `315` фото MeterFL и MeasureBench — локализация `79,0 %`, средняя ошибка `5,8 %` шкалы; полевой проверки в цеху не было; автокалибровка исключена (`1 из 5`).
- **Прогноз:** синтетический дрейф E2E — `13,18 мин` (`12,01–14,59`) при факте `12,7 мин`; реальные данные (`4` датасета, `82` ряда, `14 760` проверок) — полнота пересечений `4,65 %`, ложные срабатывания `36,1 %` (подсказка инженеру, не ПАЗ).
- **Оптимизатор:** `1500 / 1500` совпадений с перебором и HiGHS, `748 / 748` минимальных бюджетов, масштабирование до `1000` объектов; план E2E — `4` позиции на `383 040 ₽` при бюджете `450 000 ₽`, `ТЗ-КИП-20261127-01`.
- **Матрицы требований (раздельно):** `RTM_ORIGINAL.csv` — `96,95 / 100` (`72 PASS / 2 PARTIAL / 0 FAIL / 1 NOT VERIFIED`, методика аудита); `RTM_NEXT_GEN.csv` — `2 PASS / 3 PARTIAL / 1 FAILED`.
- **Готовность:** демонстрация и прототип `READY`, лабораторная интеграция `READY с ограничениями`, ограниченный пилот `CONDITIONAL`, промышленная эксплуатация `NOT READY`. Не средство измерений и не ПАЗ.

## 7. Известные ограничения сайта

1. Ролик листа `02` (`shift.scrub.mp4` / `shift.scrub-m.mp4`) — иллюстрация, сгенерированная Gemini, а не съёмка со стенда; явно подписан штампом «Иллюстрация».
2. Данные состояния 8 приборов в интерактивном оптимизаторе — условные демонстрационные; точный перебор 256 наборов работает по реальным формулам `app/modernization_optimizer.py` и каталогу `app/spec_generator.py`.
3. Стоимость камеры `33 000 ₽` в калькуляторе экономики — оценка команды v2, подписана и доступна для редактирования.
4. На реальном снимке `hmi-dispatch.jpg` присутствует демонстрационная плашка пульта «Окупаемость 5 мес.» (36 условных позиций); в тексте сайта эта оценка не используется.
5. При первичном открытии страницы синхронный монтаж 11 листов даёт 1–2 длинные задачи (`155–227 мс`); во время прокрутки просадок нет.
6. Полная высота страницы на `390×844` составляет `37,1 тыс. px`; для быстрой навигации есть фиксированная панель 11 закладок и режим демонстрации.
7. На Tilda внешние ресурсы раздаются с `static.tildacdn.pub` и `cdn.jsdelivr.net` (`@c12b2a9`); полностью автономный показ без сети обеспечивается локальным запуском `site/v5`.
8. Контакты ограничены репозиторием и шаблоном issue на GitHub — телефонов и адресов почты в источниках релиза нет.
