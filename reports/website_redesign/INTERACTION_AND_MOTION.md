# Взаимодействие и движение сайта GaugeVision AI 3.0 (v5)

## 1. Принципы

1. **Движение объясняет механику прибора и системы.** Стрелка манометра подпружинена и подаёт живые показания в сменный журнал, пакеты MQTT накапливаются при обрыве и досылаются без пропусков, область неопределённости прогноза разворачивается по времени, а плитки плана модернизации перестраиваются через FLIP.
2. **Единый цикл кадра (`GV.motion`).** Все покадровые обновления и прокрутка идут через один `requestAnimationFrame` (`onFrame`, `onScroll`), с разделением измерений и записи. Симуляции журнала и Store-and-Forward останавливаются за пределами видимости (`IntersectionObserver`) и при скрытии вкладки.
3. **Только композитные свойства.** Анимации работают через `transform` и `opacity`. Для исключения сдвигов макета при загрузке шрифта предзагружаются `sofia-xcond-cyrillic.woff2` и `martian-mono-cyrillic.woff2`, а строки заголовка первого экрана зафиксированы без переноса на экранах шире `760 px` (CLS `0,000–0,001` локально).
4. **Полноценный режим `prefers-reduced-motion: reduce`.** Все CSS-переходы и анимации отключены, вместо прокручиваемого ролика смены выводится пара статических кадров «до / после», Store-and-Forward и график прогноза переключаются мгновенно, без запущенных анимаций и играющих видео (`0` / `0`).

## 2. Длительности и кривые (`site/v5/css/tokens.css`)

| Токен | Значение | Применение |
|---|---|---|
| `--dur-fast` | `160 мс` | Наведение кнопок, магнитный сдвиг штампа, скрытие ярлыка |
| `--dur-med` | `320 мс` | Боковые закладки, перекрёстное затухание кадров щита, полосы экономики |
| `--dur-slow` | `700 мс` | Появление блоков (`[data-reveal]`), отметки времени на полях, подписи ролика |
| `--dur-write` | `1100 мс` | Рукописное «написание» первой строки обходчика и подписи сдачи смены |
| `--ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | Основная кривая выхода |
| `--ease-in-out` | `cubic-bezier(0.65, 0, 0.35, 1)` | Плавные переходы состояния |

## 4. Измерения плавности прокрутки

Скрипт `reports/website_redesign/evidence/scripts/accept_v5.mjs` прокручивает всю страницу шагами по `1/6` окна и замеряет частоту кадров (`requestAnimationFrame`), сдвиги (`layout-shift`) и длинные задачи (`longtask`) в Microsoft Edge:

| Разрешение | Локально (`site/v5`): FPS / p95 / CLS | Эмуляция Tilda: FPS / p95 / CLS |
|---|---|---|
| `1920×1080` | `59,9` / `16,8 мс` / `0,001` | `60,1` / `16,8 мс` / `0,001` |
| `1440×900` | `60,0` / `16,8 мс` / `0,000` | `60,0` / `16,8 мс` / `0,001` |
| `1280×720` | `60,0` / `16,8 мс` / `0,000` | `60,0` / `16,8 мс` / `0,002` |
| `768×1024` | `60,0` / `16,8 мс` / `0,000` | `60,0` / `16,8 мс` / `0,001` |
| `390×844` | `60,0` / `16,8 мс` / `0,001` | `60,0` / `16,8 мс` / `0,001` |

На всех пяти разрешениях зафиксировано `0` кадров длиннее `50 мс` (худший кадр `17 мс`). Единственная длинная задача (`174–227 мс` локально) приходится на первичный синхронный монтаж 11 листов при открытии страницы; во время прокрутки и работы интерактивных виджетов просадок нет.
