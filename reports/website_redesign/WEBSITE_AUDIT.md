# Аудит существующих версий сайта GaugeVision AI

Дата: 27.11.2026. Объекты: опубликованный сайт https://gaugevs.tilda.ws/, локальные версии v2 (`site/` на ветке
`GaugeVision-2.0`, коммит 94e646e) и v3 (Tilda-исходник `site/` из истории `GaugeVision-3.0`). Для сравнения тем же
скриптом снята новая версия v4 (`site/v4`).

Метод: настоящий браузер Microsoft Edge (Playwright, без расширений), четыре разрешения 1920×1080, 1440×900,
768×1024, 390×844. На каждом разрешении: первый экран сразу и через 4 с, пошаговая прокрутка всей страницы со
снимками, полная страница, сетевые запросы с доменами и размерами, ошибки консоли, горизонтальное переполнение,
CSS-переменные `:root`, загруженные шрифты, типографика заголовков, список секций, DOM после выполнения скриптов,
CSS-анимации. Опубликованный сайт только читался: ни настройки проекта Tilda, ни страница не изменялись.

Материалы: `evidence/audit/*_audit.json` (сырые данные), `evidence/screenshots/before/` (первые экраны и полные
страницы), `evidence/scripts/audit.mjs` (скрипт).

## 2. Опубликованный сайт (= v3, «Журнал обходчика»)

**Концепция.** Лист бумажного журнала: светлая «бумага» `#EEF0EE`, линовка, красное поле, рукописный шрифт
Bad Script в записях, сверхузкий Sofia Sans Extra Condensed 168 px в заголовках, маркерные выделения `#EBD45A`.
Восемь листов: «Прибор пишет журнал сам», «Двенадцать часов против трети секунды», «От угла θ к мегапаскалям»,
«Четыре операции над одним кадром», «Протокол испытаний», «Один сервер в локальном контуре», «Компромиссы,
ограничения и план», «Журнал открыт на GitHub». Справа — ярлыки листов 01–08.

**Сильные стороны.**
- Узнаваемая метафора, которая объясняет продукт без слов: журнал заполняет себя сам.
- Живой прибор на первом экране: стрелка двигается, строки журнала дописываются (`gv-row-in`, `gv-stamp`).
- Сцена «было — стало» на ролике: обходчик с журналом сменяется камерой на поручне.
- Честный лист ограничений и открытый код.

**Проблемы.**
- Содержание соответствует продукту версии 2.0. Нет ни одной возможности 3.0: несколько приборов на кадре,
  живая интеграция с Ignition, прогноз, оптимизатор модернизации, ТЗ из плана, комплексная приёмка.
- Ключевые цифры — оценки команды без источника: «до 60 % приборов ТЭЦ не подключены к АСУ ТП», «−58 % затрат
  на точку», «26,7 млн ₽ на 100 приборах». Подпись «по оценке команды» есть, ссылки на расчёт или документ нет.
- Светлая бумажная палитра теряется на проекторе: тонкие линии линовки `rgba(66,104,150,0.16)` и серый текст
  `#5C626A` на `#EEF0EE` при засветке экрана сливаются.
- Сцена ролика занимает около 4800 px прокрутки (лист 02 — 4798 px высотой): на 1920×1080 это четыре с половиной
  экрана одной сцены.
- Зависимость от трёх внешних CDN и счётчиков Tilda; ролик по jsDelivr зависит от коммита `10d8029`.
- Восемь средних точек «·» как разделителей в интерфейсе.

## 3. Локальная v2 («Пульт оператора»)

**Концепция.** Тёмный интерфейс пульта: фон `#090B0E`, акцент оранжевый `#FF5A1F`, Manrope 700 105,6 px,
JetBrains Mono для цифр. Шапка с разделами «Суть, Показание, Конвейер, Замеры, Было → Стало, Архитектура,
Ограничения», строка телеметрии «01 / 08», сцена-ролик «камера отъезжает от манометра».

**Сильные стороны — то, что берём в v4.**
- Модульная архитектура без фреймворка: пространство имён `GV`, `util`, `motion` (единый rAF-цикл, `onScroll`,
  `pinProgress`, пружины, reduced motion), `kit` (области очистки, навигация, иконки, внешние ссылки),
  компоненты `mount(el) → { destroy }`, тексты в `content.js`.
- Панель Tweaks: шрифт, масштаб интерфейса, глубина фона — настройки сохраняются в `localStorage`.
- Прокрутка ролика по кадрам (`scroll-video`) с мобильной версией файла.
- Точный прибор `precision-dial` с формулой перевода угла в МПа.
- Тёмная палитра хорошо держится на проекторе.

**Проблемы.**
- Между первым экраном и секцией «От угла θ к МПа» — пустой тёмный экран: на снимках прокрутки кадры 6–7
  совершенно чёрные (`evidence/screenshots/before/v2/`). Сцена закреплена дольше, чем длится её содержание.
- Содержание — версия 2.0, без возможностей 3.0.
- Оранжевый акцент ассоциируется с тревогой: в HMI оранжевый и красный зарезервированы под отклонения
  (ISA-101), а на сайте им выделены обычные кнопки.
- 12 средних точек «·» в тексте.

## 4. Что переносится в v4, что меняется

| Решение | Источник | В v4 |
|---|---|---|
| Каркас `GV`, `util`, `motion`, `kit`, Tweaks, `mount/destroy` | v2 | перенесён без изменений (файлы скопированы) |
| Тёмная палитра, Manrope + JetBrains Mono | v2 | сохранены; акцент сменён на циан `#4FD8E8`, оранжевый оставлен только для статуса H |
| Ролик «камера отъезжает от манометра» с прокруткой по кадрам | v2 | перенесён в первый экран |
| Живой прибор, сцена «было — стало» | v3 | прибор перерисован в SVG для истории PI-102; «было — стало» — шторка в секции «Задача» |
| Лист ограничений и открытый код | v3 | расширены: уровни готовности, ограничения со ссылками на отчёты |
| Цифры «по оценке команды» | v3 | убраны; каждая цифра — со ссылкой на документ тега v3.0.0 |
| Внешние CDN | опубликованный | нет: шрифты, ролики и картинки локальные, 0 внешних запросов |
