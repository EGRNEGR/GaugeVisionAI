# GaugeVision AI — правила дизайна страницы «Циферблат»

Одна страница на основе бывшего варианта B. Сайт держит кадр, пока автор рассказывает голосом на защите:
дорого, тихо, точно. Слов минимум — заголовки 3–6 слов, цифры с условиями замера, формулы, живые блоки.
Каждая цифра — из `README.md`, `PRODUCT.md` или кода (`site/js/content.js`, сверяет `site/tests/check.js`).

Источник истины для значений — `css/tokens.css`. Этот файл описывает правила; при расхождении прав `tokens.css`.

## 2. Токены

### Цвет (обсидиан)

| Токен | Значение | Назначение | Контраст к `#090B0E` |
|---|---|---|---|
| `--bg-canvas` | `#090B0E` | цвет `html`, верх градиента фона, шапка | — |
| `--bg-ambient` | обсидиан сверху → `#150C08` к низу экрана + тёплые пятна 0,06 и 0,05 | фон страницы: неподвижный слой `.gv-ambient` | — |
| `--bg-surface` | `#0E1115` | карточки трека конвейера, узлы схемы | — |
| `--bg-elevated` | `#13171C` | Tweaks, всплывающее | — |
| `--border-hairline` | `rgba(230, 234, 239, 0.07)` | структурные линии 1px | — |
| `--border-strong` | `rgba(230, 234, 239, 0.16)` | рамки интерактивного, шапка таблицы | — |
| `--text-primary` | `#E6EAEF` | основной текст | 16,31 : 1 |
| `--text-muted` | `#A1A9B4` | подписи, условия замера | 8,30 : 1 (7,58 на `--bg-elevated`) |
| `--text-faint` | `#8D95A0` | метаданные, телеметрия | 6,51 : 1 (5,95 на `--bg-elevated`, 4,83 в худшей точке фона) |
| `--accent` | `#FF5A1F` | стрелка, текущий раздел, главная кнопка — единственный тёплый акцент | 6,32 : 1 |
| `--accent-contrast` | `#1A0802` | текст на акценте | 6,24 : 1 к акценту |
| `--status-ok` | `#6DBE8F` | НОРМА | 8,83 : 1 |
| `--status-warn` | `#D9A54E` | ПРЕДУПРЕЖДЕНИЕ | 8,86 : 1 |
| `--status-alert` | `#EE7462` | АВАРИЯ | 6,86 : 1 |

Статусы приглушённые: насыщенность ниже, чем у акцента, чтобы авария не спорила со стрелкой. Цвет статуса
всегда идёт с подписью (НОРМА / ПРЕДУПРЕЖДЕНИЕ / АВАРИЯ), не одним цветом.

### Свет

| Токен | Значение | Как применяется |
|---|---|---|
| `--edge-light` | `rgba(255, 255, 255, 0.16)` | верхний блик карточки: градиент 1px по верхнему краю, гаснет к углам |
| `--surface-card` | блик + `--bg-surface` | фон карточек трека конвейера — единственные карточки страницы |
| `--glow-warm` | `rgba(255, 90, 31, 0.09)` | тёплое пятно у метрик, ограничений и финала |
| `--glow-cool` | `rgba(150, 178, 205, 0.06)` | холодное пятно у архитектуры |
| `--glow-cursor` | `rgba(255, 138, 76, 0.16)` → `--glow-cursor-edge` 0,05 | светлое пятно фона за курсором, круг 44rem |

Карточка — это граница 1px `--border-hairline` + верхний блик, без тени (ни «призрачных» карточек, ни свечения).
Карточка есть только там, где она двигается (трек конвейера); замеры, ограничения, «Было → Стало» и подпись
архитектуры — строки таблицы на линиях 1px.
Пятна света (`.gv-glow`) — статичные радиальные градиенты за содержимым, обрезаются секцией
(`overflow-x: clip` не ломает `position: sticky`). Пятно за курсором — `GV.motion.spotlight`: слой-кольцо 1px
с маской, внутри него пятно двигается только `transform`.

Фон страницы — неподвижный слой `.gv-ambient` под всем содержимым (`z-index: −1`, у `body` своего фона нет):
градиент `--bg-ambient` и пятно `--glow-cursor`, которое ведёт `GV.motion.cursorLight`. Картинки, видео
и карточки закрывают пятно сами — свет виден только на голом фоне. Кадр hero, постер и кадр котельной
в финале тают в фон маской (`mask-image`), а не градиентом к `--bg-canvas`: на тёплом фоне такая плашка дала
бы шов. Худшая точка — правый нижний угол экрана под центром пятна, `#3F2112`: там `--accent` 4,68 : 1,
`--text-faint` 4,83 : 1. Ярче угол градиента или пятно не делать.

Вариант фона выбирает автор в Tweaks (`html[data-ambient]`; посетитель по умолчанию видит «Чертёж»,
«Тёплый» — всё описанное выше — остаётся базой CSS без атрибута):

| Вариант | Что на фоне |
|---|---|
| `warm` «Тёплый» | градиент `--bg-ambient` и тёплое пятно за курсором |
| `blueprint` «Чертёж» | ровный `--bg-canvas` с сеткой 2rem (линии 0,035); пятно за курсором проявляет ту же сетку оранжевым (линии 0,14, каждые 8rem — 0,3). Сетка внутри пятна едет навстречу ему (`cursorLight`) и стоит на месте |
| `dial` «Шкала» | тёплый фон и шкала прибора 270° справа, наполовину за краем; стрелка (акцент 0,22) показывает долю прочитанной страницы, поворот `rotate` с переходом 600 мс |
| `obsidian` «Обсидиан» | ровный `--bg-canvas`, без пятна |

Линии сетки и шкалы тоньше и тусклее текста — контраст текста считается по фону под ними.

### Шрифты

| Роль | Шрифт | Где |
|---|---|---|
| Заголовки h1–h4, итог −89 % | Onest 700 — `--weight-display`, трекинг −0,025em (`--tracking-display`) | `--font-display` = `--font-sans` |
| Текст, описания алгоритмов, UI-контролы | Onest 400/500 | `--font-sans` |
| Цифры, формулы, метаданные | JetBrains Mono 400/500/700 (вес 600 в CSS рисуется 700) | `--font-mono`, всегда `tabular-nums` |
| Tweaks: шрифт страницы | Onest · Manrope · IBM Plex Sans — меняет и текст, и заголовки; по умолчанию Manrope (на `<html>` в `index.html`), Onest — база CSS | `html[data-font]` |

Одна гарнитура на заголовки и текст: «60 % бизнес / 40 % мягкость» — геометрия Onest со скруглёнными переходами,
иерархию держат вес (700 против 400) и размер, а не смена шрифта. Все шрифты локальные (`css/fonts.css`, woff2
из fontsource, SIL OFL 1.1). IBM Plex Mono и Alegreya SC убраны вместе с файлами.

### Размеры и ритм

- Кегли текста (`tokens.css`): `--fs-2xs` 0,75rem · `--fs-xs` 0,8125rem · `--fs-s` 0,9375rem (основной текст) ·
  `--fs-m` 1,0625rem · `--fs-l` 1,1875rem (малые заголовки). Нижние ступени подняты ради читаемости; подпись узла
  схемы архитектуры в узкой раскладке держит 0,875rem — узел фиксированной ширины.
- Только `rem` (масштаб Tweaks через `--ui-scale`: 90 / 100 / 110 / 125 %, по умолчанию 110 %); `px` — линии 1px и медиазапросы;
  `vh`/`svh` — высоты закреплённых сцен.
- Вертикальный ритм: `--section-pad` = `clamp(4rem, 1.5rem + 6.5vw, 7rem)` сверху и снизу секции — на десктопе
  между секциями 14rem воздуха (бриф: «максимум воздуха», не меньше 12rem).
- Заголовок секции слева: номер моноширинным `--fs-xs` с акцентной риской 2rem — в левой колонке `--rail` (11rem),
  h2 — справа от неё, `--fs-3xl`, `--lh-tight` 1,1, не шире 20ch. Та же колонка `--rail` у меток групп замеров
  и у кнопки финала — одна вертикаль на всю страницу. Уже 900 px номер встаёт над заголовком.
  Hero — `--fs-display`, не больше 6rem.
- Отступы блоков — шаг 8pt (`--space-2`…`--space-8`); 4 и 12 px (`--space-1`, `--space-3`) — только внутри строки:
  зазор подписи и значения, поля бейджа.
- Заголовок закреплённой сцены («Показание», «Конвейер»): внутри sticky-сцены, слева, без номера и без
  надзаголовка — номер раздела уже в телеметрии (`GV.page` передаёт его модулю в `mount(body, { head })`).

## 3. Движение

Только `transform` и `opacity` — в анимациях и переходах. Цвет при наведении меняется сразу, без перехода.
Общий двигатель — `GV.motion` (`js/motion.js`): один rAF-цикл на страницу (спит без подписчиков), пассивный
scroll, геометрия кэшируется до resize и изменения высоты документа.

| Что | Как | Время |
|---|---|---|
| Видео hero | `currentTime` догоняет прогресс прокрутки с инерцией (тикет 02) | кадр за кадром |
| Стрелка прибора | `GV.motion.spring`: жёсткость 170, демпфирование 18, подшаг ≤ 1/120 с; поворот `rotate` | успокаивается < 1 с |
| Заголовки секций | `GV.motion.reveal`: слова входят по очереди, `translateY` + `opacity` | шаг 60 мс, 700 мс, один раз |
| Счётчики | `GV.motion.counter`: от 0 к значению, ease-out, конечный текст — точная строка `display` | 1,2 с |
| Пятно света | `GV.motion.spotlight`: кольцо 1px по ободку карточки трека, пятно двигается `translate3d` | за курсором, только мышь |
| Раскрытие компромисса | `GV.motion.shiftBelow`: строки ниже стартуют со старого места и доезжают `translate3d` (FLIP), пояснение проявляется `opacity` и съезжает на 0,5rem; плюс в круге 2rem становится минусом `rotate` | 320 мс сдвиг, 600 мс пояснение с задержкой 120 мс |
| Стрелка шкалы фона | вариант «Шкала»: `rotate` 135° + 270° × прогресс страницы, переход `transform` | 600 мс |
| Свет фона | `GV.motion.cursorLight`: пятно `translate3d` догоняет курсор (затухание 1 − e^(−14·dt), при reduced — сразу), появляется и гаснет `opacity` | ≈ 0,2 с, только мышь |
| Конец hero | кадр и затемнение гаснут `opacity` в фон страницы | последние 20 % прокрутки сцены |
| Трек конвейера | шаг `s` непрерывно следует за прокруткой: у краёв отрезка карточка стоит по центру (по 20 % отрезка), между ними трек переезжает по smoothstep; пружина 120 / 22 сглаживает колёсико; трек `translateX` | за прокруткой, без рывков |
| Черта шагов 01–04 | одна оранжевая черта перетекает от шага к шагу: `translateX` + `scaleX` по `s` (положение и ширина — смесь соседних шагов); полосы прогресса под шагами нет | за прокруткой |
| Схема шага | рамка детектора `scale`, эллипс → круг `rotate · scale · rotate`, стрелка и линия Hough `rotate`, кривая EMA — `scaleX` маски | по фокусу карточки |
| Столбцы масштаба | `scaleX` от 0 при первом показе, по очереди | 1,2 с, шаг 140 мс |
| Переключатель «Было / Стало» | капсула (радиус 10rem: торцы полукругом, верх и низ прямые), бегунок `translateX`; бегунок полупрозрачный, текст не перекрашивается | 600 мс, `--ease-in-out` |
| Шкала смены | отметка «Обнаружено» и заливка «наблюдения» — `transform`, окно риска — `opacity` с задержкой 320 мс; подпись под шкалой входит `opacity` + `translateY` | 1,4 с (`--dur-crawl`), окно 1 с, подпись 600 мс |
| Пинг отметки | доехав, отметка расходится кольцом 0,125rem: `scale` 0,5 → 2,4 и `opacity` → 0 | 900 мс |
| Цены и итог −89 % | `GV.motion.counter` от 0; ширину держит невидимый конечный текст, подпись рядом не прыгает | 1,6 с |
| Черта у номера секции | `scaleX` 0 → 1 вместе с появлением заголовка (`.gv-head:has(.gv-reveal.is-in)`) | 1 с, задержка 160 мс |
| Кнопка GitHub в финале | `GV.motion.magnet`: тянется к курсору на четверть расстояния, не дальше 0,5rem; иконка — на 0,6 сильнее | затухание 1 − e^(−12·dt), только мышь |
| Телеметрия | полоса `scaleX` по прогрессу страницы + «NN / 08 · NNN %» и имя раздела | каждый кадр прокрутки |
| Текущий раздел | риска над пунктом навигации `scaleY` | 320 мс |

Кривая — `--ease-out` `cubic-bezier(0.16, 1, 0.3, 1)`. Механику прибора и трека изображает не кривая, а пружина
`GV.motion.spring`. Свечений с нулевым смещением (`box-shadow: 0 0 …`) нет: активное состояние — ободок 1px.

`prefers-reduced-motion: reduce`: закреплений нет, `pinProgress` → 1, пружина сразу на цели, заголовки и
счётчики сразу в конечном состоянии, видео заменено постером. Скрытое начальное состояние ставит JS
(класс `.gv-reveal`), поэтому без скрипта всё видно.

## 4. Страница

`hero → reading → pipeline → metrics → compare → architecture → limits → contact` — восемь секций из
`GV.content.sections`, строит `GV.page` (`js/page.js`), модули секций — по таблице `GV.page.mounts`.

- Шапка: бренд-циферблат, семь якорей, один пункт «GitHub» (ссылка на репозиторий в новой вкладке). Под шапкой —
  полоса телеметрии. Уже 1100 px навигация уходит второй строкой и прокручивается внутри полосы (маска по
  правому краю); шапка уезжает вверх, у верха экрана остаётся телеметрия.
- Финал: одна главная кнопка «Код на GitHub» на приглушённом кадре котельной (Gemini, прозрачность 0,32 под
  градиентом к фону). Лицензия — «Проприетарная лицензия» в футере. Других контактов нет.
- Tweaks — инструмент автора, посетитель кнопку не видит. Адрес с `?tweaks` включает её на этом устройстве
  (запоминается, `?tweaks=off` — выключает), Shift + T — показать или спрятать. Панель: масштаб, шрифт страницы,
  фон. Пока кнопка видна, HUD hero и футер оставляют под неё место (`--tweaks-clearance`).

### Сцены и блоки

- **Показание** (`precision-dial.js`, 170vh): прибор слева, справа заголовок и показания. Под формулой — та же
  формула с подставленными θ, θmin, span и диапазоном шкалы; результат цветом зоны. Подсказка управления
  своя для мыши и для касания; клик или касание шкалы ставит стрелку. На телефоне заголовок над прибором,
  подпись калибровки остаётся только описанием слайдера (её числа уже в подстановке).
- **Конвейер** (`pipeline-track.js`, (N + 0,5) × 75vh): сверху заголовок и шаги «01 Локализация … 04 Сглаживание»
  (на телефоне имя только у активного), по центру трек, снизу итог 30–100 мс/кадр. Карточка — схема шага
  (SVG 200 × 200, линии 1px, акцент — то, что делает шаг) и текст; на телефоне схема полосой сверху.
  Задержка только у замеренных шагов. Неактивная карточка — яркость 0,85: текст в ней держит ≥ 4,5 : 1.
  Окно ниже 760px — заголовок в строку, схема уже, отступы плотнее.
- **Замеры** (`metrics.js`): группы «Точность · Скорость · Масштаб», метка группы и вид данных слева. Записи —
  строки одной таблицы: подпись · условие · крупная моноширинная цифра у правого края. В масштабе вместо
  условия — столбцы в одной шкале: замер залит акцентом, расчёт заштрихован цветом предупреждения и подписан
  «расчёт». На телефоне условие уходит под строку.
- **Было → Стало** (`compare.js`): две колонки без карточек — верхняя линия и вертикальный разделитель (на телефоне
  стопкой). Акцентная линия только у «Стало»; −89 % — под «Стало», по её левому краю. Переключатель в шапке
  шкалы смены ведёт отметку «Обнаружено»; в сценарии «Было» линия колонки «Было» светлеет, но не оранжевая.
- **Ограничения** (`limits.js`): «Компромиссы» — строки с полями 1rem, плюс в круге 2rem; «Выбрали → платим»
  подписано в шапке, в строках метки только для чтения с экрана (кроме телефона). «Ограничения среды» — таблица
  «условие и статус · риск · ответ в коде» с одной шапкой колонок; фильтр по статусу прячет строки.
- **Архитектура**: несвязанные узлы гаснут рамкой и фоном, а не `opacity` — текст держит контраст. Подпись узла —
  строка под схемой с линией сверху; пока узел не выбран, видна одна строка подсказки.

## 5. Доступность

- Текст ≥ 4,5 : 1 (таблица выше), фокус — обводка 2px `--accent` с отступом 2px.
- Порядок Tab совпадает с визуальным: бренд → якоря → GitHub → содержимое секций сверху вниз.
- Ссылка в новой вкладке: иконка «наружу» + визуально скрытое «(откроется в новой вкладке)» — делает `kit.extLink`.
- Битый адрес (`#%E0`) игнорируется: страница строится, хэш не применяется.
- Цели касания ≥ 2,75rem.
