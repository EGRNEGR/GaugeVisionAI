# GaugeVision AI — правила дизайна страницы «Циферблат»

Одна страница на основе бывшего варианта B. Сайт держит кадр, пока автор рассказывает голосом на защите:
дорого, тихо, точно. Слов минимум — заголовки 3–6 слов, цифры с условиями замера, формулы, живые блоки.
Каждая цифра — из `README.md`, `PRODUCT.md` или кода (`site/js/content.js`, сверяет `site/tests/check.js`).

Источник истины для значений — `css/tokens.css`. Этот файл описывает правила; при расхождении прав `tokens.css`.

## 2. Токены

### Цвет (обсидиан)

| Токен | Значение | Назначение | Контраст к `#090B0E` |
|---|---|---|---|
| `--bg-canvas` | `#090B0E` | фон страницы (бриф) | — |
| `--bg-surface` | `#0E1115` | карточки | — |
| `--bg-elevated` | `#13171C` | Tweaks, всплывающее | — |
| `--border-hairline` | `rgba(230, 234, 239, 0.07)` | структурные линии 1px | — |
| `--border-strong` | `rgba(230, 234, 239, 0.16)` | рамки интерактивного, контурные цифры | — |
| `--text-primary` | `#E6EAEF` | основной текст | 16,31 : 1 |
| `--text-muted` | `#A1A9B4` | подписи, условия замера | 8,30 : 1 (7,58 на `--bg-elevated`) |
| `--text-faint` | `#868E99` | метаданные, телеметрия | 5,95 : 1 (5,44 на `--bg-elevated`) |
| `--accent` | `#FF5A1F` | стрелка, текущий раздел, главная кнопка — единственный тёплый акцент | 6,32 : 1 |
| `--accent-contrast` | `#1A0802` | текст на акценте | 6,24 : 1 к акценту |
| `--status-ok` | `#6DBE8F` | НОРМА | 8,83 : 1 |
| `--status-warn` | `#D9A54E` | ПРЕДУПРЕЖДЕНИЕ | 8,86 : 1 |
| `--status-alert` | `#EE7462` | CRITICAL | 6,86 : 1 |

Статусы приглушённые: насыщенность ниже, чем у акцента, чтобы авария не спорила со стрелкой. Цвет статуса
всегда идёт с подписью (НОРМА / ПРЕДУПРЕЖДЕНИЕ / CRITICAL), не одним цветом.

### Свет

| Токен | Значение | Как применяется |
|---|---|---|
| `--edge-light` | `rgba(255, 255, 255, 0.16)` | верхний блик карточки: градиент 1px по верхнему краю, гаснет к углам |
| `--surface-card` | блик + `--bg-surface` | фон карточек: метрики, «Было → Стало», подпись архитектуры, ограничения |
| `--glow-warm` | `rgba(255, 90, 31, 0.09)` | тёплое пятно у метрик, ограничений и финала |
| `--glow-cool` | `rgba(150, 178, 205, 0.06)` | холодное пятно у архитектуры |

Карточка — это граница 1px `--border-hairline` + верхний блик, без тени (ни «призрачных» карточек, ни свечения).
Пятна света (`.gv-glow`) — статичные радиальные градиенты за содержимым, обрезаются секцией
(`overflow-x: clip` не ломает `position: sticky`). Пятно за курсором — `GV.motion.spotlight`: слой-кольцо 1px
с маской, внутри него пятно двигается только `transform`.

### Шрифты

| Роль | Шрифт | Где |
|---|---|---|
| Текст и заголовки | Onest 400/500/700/800 | `--font-sans`, `--font-display` |
| Цифры, формулы, метаданные | IBM Plex Mono 400/500/600 | `--font-mono`, всегда `tabular-nums` |
| Tweaks: шрифт страницы | Onest · Manrope · IBM Plex Sans | `html[data-font]` |

Все шрифты локальные (`css/fonts.css`, woff2, SIL OFL 1.1). JetBrains Mono убран вместе с файлами.

### Размеры и ритм

- Только `rem` (масштаб Tweaks через `--ui-scale`: 90 / 100 / 110 / 125 %); `px` — линии 1px и медиазапросы;
  `vh`/`svh` — высоты закреплённых сцен.
- Вертикальный ритм: `--section-pad` = `clamp(4rem, 1.5rem + 6.5vw, 7rem)` сверху и снизу секции — на десктопе
  между секциями 14rem воздуха (бриф: «максимум воздуха», не меньше 12rem).
- Заголовок секции: контурный номер (`-webkit-text-stroke` 1px) за h2, h2 — `--fs-2xl`, 800, трекинг −0,025em,
  не шире 20ch. Hero — `--fs-display`, не больше 6rem.

## 3. Движение

Только `transform` и `opacity` — в анимациях и переходах. Цвет при наведении меняется сразу, без перехода.
Общий двигатель — `GV.motion` (`js/motion.js`): один rAF-цикл на страницу (спит без подписчиков), пассивный
scroll, геометрия кэшируется до resize и изменения высоты документа.

| Что | Как | Время |
|---|---|---|
| Видео hero | `currentTime` догоняет прогресс прокрутки с инерцией (тикет 02) | кадр за кадром |
| Стрелка прибора | `GV.motion.spring`: жёсткость 170, демпфирование 18, подшаг ≤ 1/120 с; поворот `rotate` | успокаивается < 1 с |
| Заголовки секций | `GV.motion.reveal`: слова входят по очереди, `translateY` + `opacity` | шаг 60 мс, 700 мс, один раз |
| Счётчики | `GV.motion.counter`: от 0 к значению, ease-out, конечный текст — точная строка `display` | 1,2 с |
| Пятно света | `GV.motion.spotlight`: кольцо 1px, пятно двигается `translate3d` | за курсором, только мышь |
| Телеметрия | полоса `scaleX` по прогрессу страницы + «NN / 08 · NNN %» и имя раздела | каждый кадр прокрутки |
| Текущий раздел | риска над пунктом навигации `scaleY` | 320 мс |

Кривая — `--ease-out` `cubic-bezier(0.16, 1, 0.3, 1)`; пружинная `--ease-spring` — только там, где движение
изображает механику прибора.

`prefers-reduced-motion: reduce`: закреплений нет, `pinProgress` → 1, пружина сразу на цели, заголовки и
счётчики сразу в конечном состоянии, видео заменено постером. Скрытое начальное состояние ставит JS
(класс `.gv-reveal`), поэтому без скрипта всё видно.

## 4. Страница

`hero → reading → pipeline → metrics → compare → architecture → limits → contact` — восемь секций из
`GV.content.sections`, строит `GV.page` (`js/page.js`), модули секций — по таблице `GV.page.mounts`.

- Шапка: бренд-циферблат, семь якорей, один пункт «GitHub» (ссылка на репозиторий в новой вкладке). Под шапкой —
  полоса телеметрии. Уже 1100 px навигация уходит второй строкой и прокручивается внутри полосы (маска по
  правому краю); шапка уезжает вверх, у верха экрана остаётся телеметрия.
- Финал: одна главная кнопка «Код на GitHub» на приглушённом кадре котельной (Gemini, прозрачность 0,32 под
  градиентом к фону). Лицензия — «Проприетарная лицензия» в футере. Других контактов нет.
- Tweaks: плавающая кнопка справа внизу, панель — масштаб и шрифт. Футер снизу оставляет под неё место.

## 5. Доступность

- Текст ≥ 4,5 : 1 (таблица выше), фокус — обводка 2px `--accent` с отступом 2px.
- Порядок Tab совпадает с визуальным: бренд → якоря → GitHub → содержимое секций сверху вниз.
- Ссылка в новой вкладке: иконка «наружу» + визуально скрытое «(откроется в новой вкладке)» — делает `kit.extLink`.
- Битый адрес (`#%E0`) игнорируется: страница строится, хэш не применяется.
- Цели касания ≥ 2,75rem.
