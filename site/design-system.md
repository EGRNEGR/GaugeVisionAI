# GaugeVision AI — правила дизайна лендинга

Эстетика — Tactical HUD Minimalism / Technical Precision (скилл tactical-hud-web-design, `brief.md`). Сайт должен выглядеть как приборная панель инженера, а не как промо стартапа: глубокий графит, линии 1px, моноширинные цифры, живые блоки вместо текста. Главный критерий доверия — честность: каждая цифра с условиями замера, стенд подписан как стенд, расчёт — как расчёт (PRODUCT.md, принципы 1–2).

Источник истины для значений — `css/tokens.css`. Этот файл описывает правила; при расхождении прав `tokens.css`, и расхождение исправляется здесь.

### Шрифты

| Токен | A · Пульт | B · Циферблат | C · Протокол |
|---|---|---|---|
| `--font-display` | Manrope 800 | Onest 800 | IBM Plex Sans 700 |
| `--font-sans` | Manrope 400/500/700 | Onest 400/500/700 | IBM Plex Sans 400/500/700 |
| `--font-mono` | JetBrains Mono 400/500/700 | IBM Plex Mono 400/500/600 | IBM Plex Mono 400/500/600 |
| `--font-chrome` | JetBrains Mono — студийная панель и Tweaks во всех вариантах | | |

Все шрифты лежат в `assets/fonts/` (woff2, кириллица + латиница; греческий для θ, α, φ и latin-ext для ₽, где семейство их содержит), лицензия SIL OFL 1.1, `font-display: swap`. CDN не используется: сайт, как и продукт, работает офлайн. Tweaks может заменить пару на Manrope + JetBrains Mono, Onest + IBM Plex Mono или IBM Plex Sans + Plex Mono (`html[data-font][data-variant]`, сильнее варианта).

Моноширинный — только для данных: цифры метрик, θ, единицы, имена констант и файлов, индексы `01 ·`, метаданные. Не для заголовков и абзацев.

### Типографическая шкала

| Токен | Значение | Где |
|---|---|---|
| `--fs-2xs` | 0,6875rem (11 px) | подписи осей, метки на схеме |
| `--fs-xs` | 0,75rem (12 px) | капс-метаданные (`--tracking-caps` 0,08em) |
| `--fs-s` | 0,875rem (14 px) | условия замера, параметры |
| `--fs-m` | 1rem (16 px) | основной текст, `--lh-body` 1,55 |
| `--fs-l` | 1,125rem | лид-абзацы |
| `--fs-xl` | clamp(1,375rem … 1,75rem) | заголовки карточек и этапов |
| `--fs-2xl` | clamp(1,75rem … 2,75rem) | заголовки секций, цифры метрик |
| `--fs-3xl` | clamp(2,25rem … 4,25rem) | крупные цифры B, заголовок запасной страницы |
| `--fs-display` | clamp(2,5rem … 5,75rem) | заголовок hero (не больше 6rem) |

Заголовки — `text-wrap: balance`, трекинг дисплея −0,03em (не ниже −0,04em), `--lh-tight` 1,05. Абзац не длиннее `--measure` 68ch и не длиннее ~60 слов. Цифры — `font-variant-numeric: tabular-nums`, русская запись: 0,38 %, 7,2 мс, 30–100 мс/кадр, неразрывный пробел между числом и единицей.

### Отступы, сетка, радиусы

- Шаг отступов: `--space-1…8` = 4, 8, 12, 16, 24, 32, 48, 80 px при масштабе 100 %. Внутри группы — 1–3, между группами — 5–6, между секциями — 8. Над заголовком места больше, чем под ним.
- Контейнер `--container` 90rem, поля `--gutter` clamp(1rem … 3rem). Сетка 12 колонок на ≥ 1100 px, 6 на 640–1099 px, 1 колонка на < 640 px.
- Брейкпоинты проверки: 1440, 900, 390/430 px.
- Радиусы: `--radius-s` 4 px (кнопки, чипы), `--radius-m` 8 px (панели), `--radius-l` 12 px (крупные рамки скриншотов). HUD держит углы почти острыми; пилюли — только для маленьких меток статуса.
- Все размеры в `rem` (масштаб Tweaks: корень `font-size: calc(100% × --ui-scale)`), `px` — только линии 1px и медиазапросы. Хром студии (панель вариантов, Tweaks) считается в `--chrome-u = 1rem / --ui-scale` и не масштабируется.

### Линии

- Структура строится линиями 1px `--border-hairline`, а не карточками-плашками. Возвышение объявляется один раз: либо линия, либо тень. Тень с отступом и размытием — только у плавающих элементов (Tweaks).
- Индексы секций и этапов: `01 ·`, `/01`, `00–08` — моноширинные, `--text-faint`. Номера несут смысл: порядок экранов брифа и порядок этапов конвейера.
- Угловые метки рамки (A), риски шкалы (B), волосяные таблицы (C) рисуются той же линией 1px.
- Фоновые сетки и полосы запрещены, если под ними нет настоящей шкалы или схемы.

## 3. Движение

- Easing `--ease-out` `cubic-bezier(0.16, 1, 0.3, 1)`; `--ease-in-out` для переходов состояний.
- Длительности: `--dur-fast` 160 мс (наведение, нажатие), `--dur-med` 320 мс (панели, смена фона), `--dur-slow` 600 мс (предел сканирующей линии hero).
- Анимируются только `transform` и `opacity` (плюс `clip-path` у сканирующей линии).
- Один авторский момент на страницу — сканирующая линия «Сырой кадр → Распознавание». Счётчик метрик — один раз, до 1,2 с, при первом попадании в экран; итоговое число в DOM с самого начала. EMA-симуляция останавливается вне экрана.
- `prefers-reduced-motion: reduce` отключает счётчики, сканирующую линию, симуляцию и любую прокрутку-параллакс: показывается итоговое состояние.

## 4. Статусные цвета

- Три статуса, как в коде (`classify_level`) и на пульте: норма — `--status-ok`, предупреждение — `--status-warn`, авария — `--status-alert`. Зоны уставок LL и HH — авария, L и H — предупреждение, между ними — НОРМА.
- «Реализовано» в ограничениях — `--status-ok`, «частично» — `--status-warn`, «в плане» — `--text-muted` без цвета.
- Цвет никогда не единственный носитель смысла: рядом всегда слово («Норма», «частично») или метка зоны.
- Статусный цвет не используется как декоративный акцент. В варианте C акцент серебряный, а янтарный `--status-warn` остаётся только статусом.
- Метрики подписываются видом: «замер» — без цвета, «расчёт» — `--status-warn` с текстовой меткой «расчёт».

## 5. Три варианта

Все три — полные страницы из семи экранов в порядке брифа (`hero`, `metrics`, `pipeline`, `compare`, `architecture`, `limits`, `contact`), на графите, с одними фактами из `js/content.js`. Различаются сеткой и композицией, а не цветом.

| | A · Пульт | B · Циферблат | C · Протокол |
|---|---|---|---|
| Идея | HUD-пульт оператора | прибор как сцена: шкала и стрелка | протокол испытаний и даташит |
| Композиция hero | асимметричная сетка 12 колонок: слева заголовок, лид и кнопки (5 колонок), справа hero-stage в рамке с угловыми метками и строкой телеметрии (7 колонок) | центр: гигантская дуга шкалы с рисками через весь экран, оранжевая стрелка поворачивается по θ; под дугой заголовок слева и лид с кнопками справа (ref5) | моноширинная шапка-метаданные (трек, версия, лицензия) и липкий индекс 01–07 слева; заголовок и hero-stage в раскладке `sheet` как лист протокола |
| Метрики | горизонтальная телеметрическая полоса `strip` с индексами `/01` и условиями под каждой цифрой | крупные контурные цифры `dial` (только обводка, как «26» на ref4) | таблица `table`: показатель · значение · условия · вид |
| Конвейер | горизонтальная лента этапов `rail` 00–08, панель деталей снизу | этапы — риски на дуге `arc`, выбранная риска подсвечена акцентом | вертикальная шкала `timeline` с формулой у каждого этапа |
| Hero-stage | `framed` | `dial` | `sheet` |
| Сравнение / ограничения | `split` / `cards` | `toggle` / `cards` | `split` / `rows` |
| Акцент | холодный циан `#4FD1E8` | оранжевая стрелка `#FF5A1F` — единственный акцент | холодное серебро `#C3CCD8`, янтарь только для статусов |

## 6. Студийная панель и Tweaks

- **Студийная панель** `#gv-studio` — тонкая полоса сверху, 40 px на десктопе (48 px на экранах < 640 px, чтобы кнопки были ≥ 44 px). Кнопки «A · Пульт», «B · Циферблат», «C · Протокол» с `aria-pressed`; показываются только существующие варианты, при их отсутствии панель честно пишет, что вариантов нет. Выбор хранится в `?v=` и localStorage `gv.variant`, при переключении сохраняется секция, которая была в зоне видимости.
- **Tweaks** — плавающая кнопка в правом нижнем углу, панель с четырьмя группами на нативных radio:
  - шрифт: по варианту / Manrope / Onest / Plex;
  - фон: Графит / Антрацит / Сине-графитовый / Бумага;
  - масштаб: 90 / 100 / 110 / 125 %;
  - изображения: Скриншоты / Схема (`data-media="schematic"` — hero-stage рисует SVG-циферблат вместо скриншотов).
- Применяется мгновенно атрибутами `<html>` и событием `gv:tweaks`, хранится в localStorage `gv.tweaks`, кнопка «Сбросить» возвращает значения по умолчанию. Esc закрывает панель и возвращает фокус на кнопку.
- Атрибуты ставятся до первой отрисовки (короткий скрипт в `<head>`), поэтому сохранённая «Бумага» не мигает графитом.
- Панель остаётся в итоговой сборке: её прямо просит бриф (правило скилла убирать Tweaks в продакшене здесь уступает брифу).
- Хром студии использует `--font-chrome` и `--chrome-u`, поэтому не меняет шрифт и размер вместе со страницей и не мешает сравнивать варианты.

## 7. Чек-лист доступности

- [ ] `<html lang="ru">`, один `<h1>` на вариант, секции с заголовками `<h2>`.
- [ ] Каждый интерактивный элемент — нативный `<button>`, `<a>` или `<input>`; нет мёртвых кнопок, вкладок и ссылок.
- [ ] Видимый `:focus-visible` (2 px акцента со смещением) на всех элементах, включая radio в Tweaks.
- [ ] Вкладки этапов — `role="tablist"`, roving tabindex, ←/→/Home/End (`GV.util.rovingTabs`); переключатели — `aria-pressed`.
- [ ] Контраст текста ≥ 4,5:1 на всех четырёх фонах, крупного текста ≥ 3:1; цвет статуса всегда продублирован словом.
- [ ] Цели касания ≥ 44 × 44 px на ширине 390 px; нет горизонтальной прокрутки на 1440, 900, 430 и 390 px.
- [ ] `prefers-reduced-motion` отключает необязательную анимацию; итоговые значения видны без анимации.
- [ ] У всех скриншотов осмысленный `alt`, у SVG-схем — `<title>` или подпись; декоративный SVG — `aria-hidden="true"`.
- [ ] Без JavaScript `<noscript>` показывает название, фразу о продукте и ссылку на GitHub.
- [ ] Ссылки наружу (GitHub, PDF, лицензия) открываются в новой вкладке с `rel="noopener"`.
- [ ] Выделение текста, полоса прокрутки и подчёркивание ссылок окрашены токенами, а не браузерными значениями по умолчанию.
